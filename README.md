## 搬瓦工促销现在是什么状态

一句话：常规优惠码全部失效，下单时优惠码一栏留空即可。

搬瓦工的优惠码是「循环折扣」——用码购买的机器，以后每次续费都按折扣价算，这是它和很多一次性优惠券的区别。历史上常规码的力度在 6%–7% 之间，只有大促才会放出 10% 上下的码。目前的失效情况：

失效的原因和一次政策调整有关：2025 年双十一搬瓦工放出 11% 循环码 ILOVEBANDWAGON 的同时，取消了之前长期可用的常规优惠码；活动结束后这个码也没了。2026 年 2 月短暂上线的 NODESEEK2026 只活了两天左右。之后 3 月到 9 月都没有任何活动，2026 年双十一官方尚无消息。

## 购买流程与常见问题

**优惠码在哪里填？** 选好套餐、付款周期和机房后点 Add to Cart，购物车页面的 Promotional Code 输入框填码，点 Validate Code。页面显示折扣价即生效；目前没有可用码，留空直接结账就行。

**支持什么付款方式？** 官网界面是英文的，但支持支付宝和银联，国内用户不必准备外币卡。另外官网主域名在国内直接打开经常失败，建议用官方镜像站（如 bwh81.net）访问，联盟链接在镜像域名下同样有效。

**续费怎么算？** 搬瓦工采用国外通用的账单模式，不能一次买多年；VPS 到期后一周内系统生成新账单并邮件通知，一周内续费即可。之前用循环折扣码买的机器，续费自动延续折扣价。

**不想要了能退吗？** 官网常规套餐标注 30 天退款政策；第三方整理的条款显示，退款要求流量使用不超过 10%，且按账户注册时间而非单台机器的购买时间计算——如果你的账户已经用了很多年，新购机器也未必能退，下单前想清楚。

**IP 被墙了怎么办？** 可以付费换 IP，价格是波动的，目前约 $8.79 一次，在 KiwiVM 后台操作。
